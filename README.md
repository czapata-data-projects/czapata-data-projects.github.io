# 1️⃣ Proyecto 1

Título: Movilidad Urbana y Productividad Económica en Ciudades de LATAM | Bootcamp de Tripleten (2026)

Problema: Identificar en qué ciudades invertir en infraestructura de transporte para mejorar la productividad y el bienestar de la población.

Qué hice: 

  ●	Realicé limpieza y transformación de datos sobre 2 DataFrames usando Python, Pandas y NumPy en Jupyter Notebook.
  
  ●	Integré y analicé datos de movilidad urbana y productividad económica, generando visualizaciones con Matplotlib y Seaborn.

Resultado del aprendizaje: Identifiqué oportunidades de inversión a largo plazo en ciudades con altos índices de congestión y desempleo.

🛠️ Skills: Python, Jupyter Notebook, Pandas, Numpy, Seaborn, Matplotlib.

# 2️⃣ Proyecto 2

Título: Análisis de Embudo y Retención para MercadoLibre | Bootcamp de Tripleten (2026)

Problema: La necesidad de visualizar el comportamiento de los usuarios en el embudo de ventas para reducir el abandono.

Qué hice: 

  ●	Limpié y filtré datos con SQL, eliminando duplicados para obtener un dataset confiable del período 2025.
  
  ●	Calculé tasas de retención por cohorte y por semana, identificando patrones de comportamiento del usuario a lo largo del tiempo.

Resultado del aprendizaje: Detecté el punto crítico de mayor pérdida de clientes, generando insights accionables para optimizar las estrategias de retención.

🛠️ Skills: SQL, Google Sheets, Visualización de Datos.
